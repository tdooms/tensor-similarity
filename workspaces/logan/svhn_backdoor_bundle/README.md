# SVHN backdoor — tensor-similarity heatmap bundle

Train a 1-layer bilinear model on grayscale SVHN, inject a backdoor mid-training
(black 5w×7t diamond in the upper-right → label 9), and visualize how the
weight-space and output-space pairwise similarities across training checkpoints
react to the backdoor onset.

## Files

```
data.py             SVHN download + grayscale conversion + diamond-stamp helpers
model.py            SVHNBilinear: Bilinear(1024 → d_hidden) → Linear(d_hidden → 10)
train.py            two-phase training loop + checkpointing + ASR / poison-loss eval
similarity.py       computes the 5 pairwise NxN matrices + per-class slice tensor
plot.py             renders results/summary.png  (acc + loss + 5 stacked heatmaps)
slice_plot.py       renders results/slice_similarity.png  (2×5 per-class slice grid)
preview_diamond.py  renders results/diamond_preview.png  (clean→poisoned image pairs)
README.md           this file
```

`model.py` and `similarity.py` import `Bilinear` and `symmetric_similarity`
from the sibling `grokking_summary_bundle/core/` so the symmetric inner-product
machinery is shared with the modular-addition figure.

## Reproduce from scratch

```bash
uv run python preview_diamond.py    # ~30s incl. SVHN download (~250MB) on first run
uv run python train.py              # ~17s on a recent GPU
uv run python similarity.py         # ~30s
uv run python plot.py               # ~5s — reads training_history.json + similarity_matrices.npz
uv run python slice_plot.py         # ~5s — reads similarity_matrices.npz
```

The data files written under `results/` (`training_history.json`,
`similarity_matrices.npz`, `config.json`) are checked in, so you can skip
straight to `plot.py` / `slice_plot.py` to iterate on figure styling without
re-training.

## Design notes

- **Trigger**: solid black diamond (rhombus) in a 5w × 7t bbox, top-right
  corner with 2px margin. (3w would collapse to a "+" under the rhombus
  formula — too narrow to read as a diamond.)
- **Two phases**: 8000 clean steps (long enough for clean test acc to plateau
  ~0.81) then 2000 steps with 10% per-batch poisoning. The poison rule applies
  even when the original label was already 9 (no-op there).
- **Input noise**: σ=0.05 Gaussian noise on inputs every train step.
- **Linear checkpoint schedule**: every 250 steps (41 checkpoints total) so
  the heatmap and curve x-axes are linearly spaced and align directly.
- **Cosine on logits, not softmax**: `softmax` is non-linear and does not
  preserve angles, so `cos(softmax(a), softmax(b)) ≠ cos(a, b)`. We follow the
  grokking bundle's convention of cosine-on-logits.
- **Eval-set size**: cosine similarity is averaged per-sample, so we use
  train+test combined (~99k) for higher signal-to-noise.

## What the figures show

### `summary.png` — five stacked NxN matrices + acc/loss curves

The phase-block "gap" (B↔B mean − A↔B mean) measures how strongly each
similarity reacts to the backdoor onset:

| matrix                    | reading                                       |
|---------------------------|-----------------------------------------------|
| `tn_sim`                  | weight-space movement is dominated by clean training |
| `act_clean_full`          | clean-input behaviour barely shifts           |
| `act_poisoned_full`       | **largest gap** — backdoor's effect lives here |
| `act_clean_2s`            | class-2 (control) is essentially unaffected   |
| `act_clean_plus_poisoned` | mixture                                       |

The loss panel includes a `poison_loss` curve evaluated at every checkpoint
(every test image stamped, label set to 9). It climbs during phase A — the
clean-trained model becomes confidently *wrong* on triggered inputs it has
never seen — and crashes within ~250 steps of phase B starting.

### `slice_similarity.png` — per-class bilinear-tensor slices

For each output class c, the slice
`B_c[i,j] = Σ_h w_p[c,h] · w_l[h,i] · w_r[h,j]` is the per-class quadratic
form. Cosine similarity of B_c across checkpoints, displayed as one NxN
heatmap per class in a 2×5 grid:

- Classes 0-8 evolve smoothly: similarity grows continuously as both i and j
  advance through training.
- **Class 9 (backdoor target)** has a sharp discontinuity at step 8000 —
  phase A and phase B form clearly separated blocks in the heatmap. This is
  the cleanest class-localized visual signature of the backdoor.

## Knobs

Edit `TrainConfig` at the top of `train.py`:
- `phase_a_steps`, `phase_b_steps` — duration of clean / backdoor phases
- `poison_rate` — fraction of each batch poisoned in phase B
- `noise_std` — Gaussian noise std on inputs during training
- `d_hidden` — bilinear bottleneck width
- `checkpoint_every` — checkpoint interval (linear schedule)

To swap the trigger from diamond → rectangle / different size, edit
`DIAMOND_W`, `DIAMOND_H`, `DIAMOND_MARGIN`, or `diamond_mask` in `data.py`.
